# Current navigation application

The installed package is `robot_navigation`. Its Streamlit entry is `app/streamlit_app.py`; the five page modules are in `src/robot_navigation/ui/`.

Launch from the repository root with `py -3 run_app.py`, or double-click the root **Start Robot Navigation.cmd**. Open the root **Robot Navigation.code-workspace** for editing. Follow [Windows installation](../docs/windows-install.md) and [the code walkthrough](../docs/code-walkthrough.md).

`configs/` and `data/` hold inputs; `runs/` holds saved current model/evaluation evidence; `artifacts/` retains scientific history. Current guides are in the root `docs/` folder. Earlier application notes were relocated to `docs/history/application/` without changing their recorded bytes. No old warehouse runtime or active automated test suite remains.
