# Versioned task inputs

`maps/bottleneck-v1.json` is the immutable starting layout, with its human-readable
image alongside it. `scenarios/` is generated by `python -m robot_navigation.cli prepare`.
Each manifest contains the complete task signature and stable ordered-pair IDs.

Train/validation/test split: 4306/928/928 of 6162 pairs, approximately 70/15/15
after rounding within goal/distance strata. The 30-scenario validation monitoring
subset is saved before training. Inspect `benchmark_report.json` for actual goal
counts, distance distribution, hashes and connected-component checks.

`test.json` is a sealed final holdout: generation and structural consistency checks
are allowed, but no final-test policy rollout, performance summary or UI browsing
has occurred. No supported milestone CLI or scenario loader evaluates that split.
Do not use it to select or debug policies. New layouts require new task versions.
