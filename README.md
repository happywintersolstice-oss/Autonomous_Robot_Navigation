# Robot Navigation

Watch a simulated robot navigate five maps, choose a route, and compare saved models.

**Start:** double-click **Start Robot Navigation.cmd**. Keep the command window open, then use **http://127.0.0.1:8517**. From a terminal, run `python run_app.py`.

The app has three main destinations: **Demo**, **Results** and **Guide**. Begin with Demo and press Play. No API key, cloud account or new training is needed.
