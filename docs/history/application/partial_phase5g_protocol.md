## Isolation and evaluation contract

Finish both training arms and destroy training model objects before launching one fresh evaluation subprocess per algorithm. Each loads the four checkpoint copies and evaluates all twenty cases in frozen original-then-expanded order with deterministic policy.act, environment reset seed0 and max200 steps per case. Register exclusive run/assessment locks and child launch offsets; no retries. Parent global RNG state, training-ledger/receipt bytes and checkpoint hashes must remain identical before/after all children. Child model/optimizer state and global RNG are checked unchanged across each panel. Loading may initialize the detached child RNG; this never touches the training process. Native assessment env.step and optimizer calls are independently witnessed, and any optimizer call fails closed.

Inputs to an RL policy are only the unchanged public observation. No diagnostic_snapshot, hidden grid, future event or shortest path enters the policy. Extra first-action score forwards occur solely in detached development assessment, never inside instrumented training. Ground-truth frozen start/goal coordinates are used only after action selection to compute metrics and check the public trajectory on the open grid. Preserve full action paths, raw public outcomes, both observation digests, first public observation and all first-action Q/probability scores.

Primary metric: first action belongs to the legal actions that strictly reduce Manhattan distance to the frozen goal on the 10x10 open grid. Denominators: combined20, original4, expanded16; combined per direction5, expanded per direction4. Legal excludes moving outside grid; Wait never reduces distance. Record invalid first moves, exact maximal-score ties, Wait and deterministic first-index argmax separately. DQN goal margin = best reducing-action Q minus best other Q; PPO uses probability difference and separate log odds, never Q-values. Right margin = score(Right) minus maximum other score, averaged over the five Right-goal cases (also preserve every case). PPO Right log odds = log(pRight/max pOther), explicitly different scales.

Secondary metrics: successes original/4 and expanded/16; expanded U/D/L/R successes/4; action counts, successful lengths, raw collisions/timeouts, Wait count divided by executed actions, moving arrivals at previously visited cells (Wait/collision stationary steps excluded), and ABAB oscillation windows over four consecutive positions with A != B. Exact open-grid shortest reference is Manhattan distance; report actual steps/reference only on successes, otherwise not_applicable. No reference is supplied to a policy.

At action2000 the frozen readiness screen requires **all**: expanded success gain >=4 over that model's checkpoint0; expanded successes >=12/16; >=2/4 successes in each direction. Classify BASIC_NAVIGATION_SCREEN_MET or BASIC_NAVIGATION_SCREEN_NOT_MET independently of measurement validity. Report all four checkpoints including deterioration; never choose a better earlier checkpoint to declare readiness. These repeatedly consulted panels are development evidence, not held-out validation or real-world navigation.
